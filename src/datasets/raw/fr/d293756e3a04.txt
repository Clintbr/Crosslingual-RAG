Pour une définition précise de ce que signifie résoudre un problème en utilisant une quantité donnée de temps et d' espace , un modèle de calcul comme la machine déterministe de Turing est utilisé . Le temps requis par une machine déterministe de Turing M sur l' entrée x est le nombre total de transitions d' état , ou pas , la machine fait avant qu' elle arrête et donne la réponse ( " oui " ou " non " ) . On dit qu' une machine de Turing M fonctionne dans le temps f ( n ) , si le temps requis par M pour chaque entrée de longueur n est au maximum f ( n ) . Un problème de décision A peut être résolu dans le temps f ( n ) s' il existe une machine de Turing fonctionnant dans le temps f ( n ) qui résout le problème . Comme la théorie de la complexité est intéressée à classer les problèmes en fonction de leur difficulté , on définit les ensembles de problèmes en fonction de certains critères . Par exemple , l' ensemble des problèmes résoluables dans le temps f ( n ) sur une machine de Turing déterministe est alors indiqué par DTIME ( f ( n ) ) .
